# Rendimiento

[PERFORMANCE_BASELINE.md](PERFORMANCE_BASELINE.md) es la línea base vigente para
comparar mediciones futuras de rendimiento. No es una garantía permanente: cada
cambio relevante de UI, datos, rutas o consultas debe medirse contra esa
referencia cuando aplique.

## Uso

- Registrar nuevas mediciones con fecha, entorno, navegador y escenario.
- Comparar contra [PERFORMANCE_BASELINE.md](PERFORMANCE_BASELINE.md) antes de declarar mejora o regresión.
- Mantener planes y cierres históricos fuera del flujo vigente.

Los documentos de planificación y cierre de Etapa 15 están en
[../archive/performance-stages/](../archive/performance-stages/).
